# Coastline

A browser-based coastal driving and exploration game project.

## Current milestone

The first milestone is a lightweight playable prototype that runs directly in a browser, with keyboard driving, a coastal road, a follow camera, and simple scenery. It is intentionally dependency-free so it can be developed and hosted at low cost.

## Run locally

Open `index.html` in a modern browser.

## Controls

- **W / Up:** accelerate
- **S / Down:** brake / reverse
- **A / Left** and **D / Right:** steer
- **Space:** handbrake
- **R:** reset car

## Hosting

Enable GitHub Pages in the repository settings and select **Deploy from a branch**, branch `main`, folder `/ (root)`. The site should then be available at `https://molson835-ai.github.io/Coastline/` after GitHub Pages finishes deploying.
