COASTLINE GODOT READY — IMPORT INSTRUCTIONS

IMPORTANT: Import the project from the ROOT of this downloaded archive. The file project.godot is at the top level beside main.tscn. Do not open the nested godot-prototype folder.

ANDROID STEPS
1. Download the ZIP from:
   https://github.com/molson835-ai/Coastline/archive/refs/heads/godot-ready.zip
2. Extract the ZIP completely using your file manager.
3. Open Godot and choose Import (or Import Existing Project).
4. Browse into the extracted folder named Coastline-godot-ready.
5. Select the project.godot file directly inside that folder, beside main.tscn.
6. Confirm Import/Open. If asked to scan/import assets, let it finish.
7. Press Play to run the project.

EXPECTED ROOT FILES
- project.godot
- main.tscn
- README-GODOT-IMPORT.txt
- scripts/main.gd

The archive also includes the original Coastline browser-game files because this is a branch of the main repository. They are not required for opening the Godot prototype. The browser game's main branch is unchanged.

NOTE
This is an experimental Godot prototype, not a full native port of the browser game. It has not been verified on your particular Android device/Godot build yet. If Godot shows an error, send me a screenshot of the error and I can help diagnose it.
