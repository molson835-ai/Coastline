# Coastline authored vehicle assets

Place the two ChatGPT-uploaded GLB files in this folder using these exact repository filenames:

- `white-four-door-sedan.glb` — source upload: `white-four-door-sedan (1).glb`
- `blue-five-door-compact-hatchback.glb` — source upload: `blue-five-door-compact-hatchback.glb`

The runtime loads these two assets only for two parked fleet slots. If either file is missing or invalid, that slot retains its existing procedural car; the game should remain playable. Keep these assets in GLB 2.0 format. The current source files are approximately 6.24 MB and 5.04 MB respectively.
